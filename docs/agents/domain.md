# Domain Docs

This repository uses a single-context documentation layout.

Before exploring relevant code, read:

- `CONTEXT.md` at the repository root, if present
- Relevant ADRs under `docs/adr/`, if present

If these files do not exist, proceed without creating them automatically. They should be created lazily when domain terms or architectural decisions need to be recorded.

Use the terminology defined in `CONTEXT.md` when writing issue titles, plans, tests, or implementation notes. If an existing ADR conflicts with proposed work, call out the conflict explicitly.
